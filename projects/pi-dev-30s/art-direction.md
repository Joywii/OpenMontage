# Build With Pi

An editorial field guide for builders, not a feature carousel. Warm paper, ink-dark code,
and leaf-green construction marks express deliberate, inspectable work. This is an
independent illustrative treatment, not Pi's official visual identity.

## Taste Profile
- Design read: a Chinese developer's notebook made tactile through precise animated examples.
- Visual variance 6/10, motion intensity 5/10, information density 3/10.
- Palette: ivory #F3F0E7, ink #18201C, leaf #4B7958; muted red only for removed code.
- Type: local Songti SC for editorial Chinese display, Heiti SC for labels and UI,
  Menlo for code, Baskerville italic for plain Pi typesetting. OS-installed fonts are
  used for raster output only; font files are not redistributed or downloaded.
- Motion: staged ease-out reveals, causal linear packet motion, restrained spring settling.
- Anti-patterns: generic neon AI, fake recordings, shared card/template spine, floating hub,
  decorative looping particles, tiny unreadable code, duplicate spoken title and captions.
- Signature: three work products become a broad Pi foundation only in the closing scene.

## Scene Distinctness
1. Negative-space question, wide serif title and three small outcome traces. Opens on paper.
2. Intimate ink code diff, actual replacement and a test. Opens on the dark code gutter.
3. Vertical repository-to-report process, branching into two paper sheets. Opens on a source marker.
4. Open conversation, asymmetrical request and response. Opens on a user request.
5. Converging outcome fragments over a green foundation, stable CTA. Opens on separate artifacts.
No adjacent scenes share their primary visual subject. No stock creative components are imported.

## References And Boundaries
Official https://pi.dev/docs/latest was inspected in a browser on 2026-10-14.
The official page shows an angular pixel symbol in its navigation and italic Pi in the
documentation heading. Neither that symbol nor official UI is recreated here. Plain
typeset Pi names the product. The palette is our proposal's independent palette.
Official text confirms CLI, SDK, RPC, extensibility, and process-level permissions.
All constructed interfaces carry an illustrative disclosure; no shipped web app or bot is implied.
